# 📊 Universal Enterprise BI Platform with AI Code Interpreter

Универсальная No-Code BI-платформа уровня Enterprise, разработанная на базе **Streamlit** и **Google Gemini Developer API**. Платформа предназначена для глубокого многомерного анализа бизнес-показателей (закупки, продажи, складская логистика) без жесткой привязки к именам колонок в исходных файлах Excel/CSV.

---

## 🚀 Ключевые архитектурные особенности

1. **🧠 Автономный ИИ Чат-Ассистент (Pandas Code Interpreter):**  
   Чат-ассистент работает локально на процессоре вашего сервера. Вместо передачи миллионов строк данных в облако (что сжигает лимиты токенов), ИИ получает только «паспорт» (структуру и типы колонок) текущей таблицы. Он «на лету» генерирует точную формулу Pandas, выполняет её на вашем компьютере и переводит результат на понятный человеческий язык.
2. **🎛️ Глобальный No-Code Маппинг Данных:**  
   Полное отсутствие жестких привязок к названиям столбцов. Пользователь вручную указывает, какие колонки файла отвечают за ключевой объект, критерий объема и шкалу времени. Все модули аналитики перестраиваются мгновенно.
3. **🔀 Модуль Сравнительного Кросс-Анализа:**  
   Универсальный реляционный конструктор связей. Позволяет сопоставлять разнородную номенклатуру внутри одной таблицы или между разными файлами (например, связать старый код категории `H02` с человеческим названием `Текущий ремонт`).
4. **🔮 Сбалансированный Трендовый Прогноз (МНК):**  
   Встроенный графический движок использует классическую линейную регрессию методом наименьших квадратов. Это гарантирует реалистичный прогноз тренда на будущие периоды без аномальных взлетов из-за случайных предновогодних всплесков продаж в последней точке.

## 🛠️ Пошаговая инструкция для пользователя

### Шаг 1: Авторизация и запуск ИИ-слоя
1. Откройте левую панель управления (сайдбар).
2. В поле **«Введите Gemini API Key»** вставьте ваш секретный ключ разработчика из Google AI Studio.
3. В выпадающем списке **«Контекст для AI»** выберите профиль, соответствующий вашему бизнес-заданию (*Продажи, Закупки, Склады* или *Сравнительный кросс-анализ*).

### Шаг 2: Загрузка массивов данных
1. Перейдите в центральную зону загрузки файлов.
2. Перетащите в окно один или несколько файлов в формате `.xlsx` или `.csv`.
3. Система сформирует единую оперативную базу данных и выведет индикатор: `База сформирована! Загружено строк: X XXX`.

### Шаг 3: Настройка аналитического пульта (Маппинг)
В левой панели в блоке **«Ручной маппинг аналитических шкал»** обязательно укажите:
*   **🔑 КЛЮЧ АНАЛИЗА:** Текстовая колонка, которую нужно исследовать (например, `Product`, `ОЗМ`, `Филиал`).
*   **💰 КРИТЕРИЙ ОБЪЕМА:** Числовая колонка для расчета масштаба (например, `Profit`, `Сумма`, `Sales`).
*   **📅 ШКАЛА ВРЕМЕНИ:** Колонка с датами, годами или месяцами для построения трендов и XYZ-анализа.

## 📊 Рекомендации по настройке под различные бизнес-задачи

### Сценарий 1: Коммерческий анализ продаж (на примере Financial Sample)
*   **Контекст для AI:** `📊 Продажи / Сбыт / Ритейл`
*   **Ключ анализа:** `Product` или `Segment`
*   **Критерий объема:** `Profit` (Чистая прибыль) или `Sales` (Выручка)
*   **Шкала времени:** `Date` или `Year`
*   **Примеры вопросов в чат:** 
    * *«Какой топ-5 продуктов по чистой прибыли?»*
    * *«Какая средняя маржинальность продаж в сегменте Government?»*

### Сценарий 2: Контроль лимитов снабжения цехов и бизнес-плана
*   **Контекст для AI:** `📅 Закупки / Материальное обеспечение`
*   **Ключ анализа:** `ПфМ` (Профильный филиал / Цех) или `Группа закупок`
*   **Критерий объема:** `Сумма`
*   **Шкала времени:** `Год` или `месяц`
*   **Примеры вопросов в чат:**
    * *«У какого ПфМ самый большой объем затрат в реестре и какова его доля от общего итога?»*
    * *«Выведи топ-3 фонда по суммам затрат для цеха 1005»*

### Сценарий 3: Выявление «мертвых» складских остатков и неликвидов
*   **Контекст для AI:** `📦 Запасы / Складские остатки`
*   **Ключ анализа:** `ОЗМ` (Код материала) или `Тип запаса`
*   **Критерий объема:** `Сумма`
*   **Шкала времени:** `Срок хранения`
*   **Примеры вопросов в чат:**
    * *«Какие ОЗМ входят в категорию CZ (стабильно лежат на складе без движения и имеют низкий приоритет)?»*
    * *«Покажи общую стоимость материалов, у которых срок хранения превышает 3 года»*

## ⚙️ Использование модуля «Сравнительный кросс-анализ»
Если названия категорий в слоях данных различаются, активируйте этот режим:
1. Выберите контекст `📊 Сравнительный кросс-анализ структур и категорий`.
2. В появившейся по центру **Панели ручного сопоставления** укажите два связующих столбца.
3. Напротив каждого базового элемента из списка выберите его эквивалент из выпадающего меню (например, укажите, что код `H02` эквивалентен строке `Текущий ремонт`).
4. Нажмите **«Применить кросс-маппинг»**. Платформа соберет сквозную витрину с полем `Унифицированная_Категория`.

## 🛡️ Технические лайфхаки и экономия токенов

*   **Минимальный расход средств:** Благодаря тому, что в Gemini API отправляется только компактная схема колонок (паспорт таблицы), стоимость одного аналитического вопроса в чате составляет менее **0.0001$**. На 1 доллар можно задать до 10 000 вопросов.
*   **Очистка истории (Сброс балласта):** При длительном общении контекст чата накапливается. Если скорость ответов замедлилась, нажмите кнопку **«🧹 Очистить историю чата»** в левой панели. Это сотрет историю прошлых расчетов, обнулит балласт токенов и ускорит работу ИИ.
*   **Обход лимитов бесплатной квоты (429 Quota Exceeded):** Если вы используете бесплатный тариф Gemini (*Free Tier*), Google ограничивает аккаунт лимитом в **20 запросов в день**. При достижении лимита создайте новый бесплатный ключ в Google AI Studio под другим Google-аккаунтом и вставьте его в поле ввода. Для безлимитной работы переведите проект в Google AI Studio на тариф *Pay-as-you-go*.
*   **Защита от сброса памяти Streamlit:** Не перезагружайте страницу браузера целиком (`F5`), если хотите сохранить загруженные файлы Excel в оперативной памяти сессии. Для переключения между конструктором графиков, таблицей и ABC-матрицей используйте исключительно круглые радио-кнопки переключения разделов в сайдбаре.
