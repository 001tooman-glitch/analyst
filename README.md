# 📊 Универсальная No-Code BI-Платформа Управления Эффективностью Снабжения и Сбыта

Высокоэффективный компилируемый аналитический комплекс промышленного уровня. Платформа предназначена для глубокого сквозного анализа больших массивов данных снабжения, логистики, бюджетирования и коммерческого сбыта крупного комбината с интеграцией нейросетей последнего поколения.

---

## ⚡ 1. Основной функционал системы

Платформа разделена на 4 независимых реактивных бизнес-раздела:

1. **🗂️ 1. Загрузка и очистка данных (Power Query Ядро)**
   * **Движок Rust Calamine**: Импорт, предобработка и очистка тяжелых файлов Excel/CSV (215 000+ строк) за 2-3 секунды.
   * **Постраничный вывод**: Отображение базы порциями по 50 строк на страницу для снятия нагрузки с оперативной памяти сервера.
   * **Авто-очистка подвалов**: Автоматическое отсечение строк «Итого», «Всего» и технических подписей.

2. **📊 2. Executive Панель Диаграмм**
   * **Умные KPI Карточки**: Динамический No-Code блок плашек с возможностью настройки шрифтов (16-48px), вертикальных отступов и автоматическим переводом миллиардных сумм в легко читаемый финансовый формат (**млн / млрд ₸**).
   * **No-Code Конструктор Графиков**: Быстрая генерация интерактивных диаграмм Plotly (Столбчатая, Линейный тренд, Кольцевая долей, Диаграмма Водопад / Waterfall). 
   * **Управление визуал-элементами**: Ползунки округления, палитра цветов элементов, поворот пончика (Donut) и слайдер отсечения визуального шума (вывод строго ТОП-15 позиций).

3. **🧮 3. Универсальный Конструктор матриц ABC/XYZ**
   * **9-польная таблица плотности**: Классическое распределение ТМЦ, цехов или агрегатов по объему влияния на бюджет (ABC) и прогнозируемости (XYZ).
   * **Тепловая BI-Карта (Heatmap)**: Интерактивная цветовая матрица плотности спроса на главном экране.
   * **Защищенная Pandas-архитектура**: Система автоматического реиндексирования (заполнения пустых ячеек нулями), защищающая дашборд от падений при выборе любых аналитических осей.

4. **👥 4. Универсальный Конструктор RFM-Сегментации**
   * **No-Code Селектор Объекта**: Полная свобода выбора категории анализа на лету. Система позволяет выполнять RFM-сегментацию не только по ОЗМ, но и по Годам, Наименованиям материалов, Агрегатам или Техническим местам.
   * **Интеллектуальное ранжирование**: Автоматическое квантование выбранного объекта по частоте событий (Frequency) и объемам затрат/сумм (Monetary) строго в рамках текущих срезов.
   * **Адаптивный алгоритм квантования**: Железобетонная математическая модель на базе ранжирования `pd.qcut`, устойчивая к жесткой фильтрации, малым объемам данных и единичным файлам.
## 🎛️ 2. Сквозная реактивная кросс-фильтрация (Cross-Filtering)

В левой панели приложения реализована каскадная система глобальных фильтров:
* **Срез №1 (Поле -> Значение)** ➡️ **Срез №2 (Поле -> Значение)**.
* Система работает в сквозном реактивном режиме. При выборе конкретного Года, Цеха или Узла оборудования (Технического места), математический движок за сотые доли секунды сужает выборку. 
* Все изменения мгновенно и одновременно пересчитывают показатели во всех 4-х разделах системы: от KPI-карточек до тепловых карт ABC/XYZ и динамических графиков RFM-сегментов.

## 🤖 3. Семантический ИИ-Ассистент (Gemini 3.5 Flash)

В BI-платформу зашито нейросетевое ядро от Google, выполняющее две критически важные функции:

### А. Интеллектуальный ИИ-Маппинг заголовков
При загрузке «грязного» файла Excel, где заголовки написаны человеческим языком (например, *«Финальный прайс с учетом НДС»*, *«Цифровой код номенклатуры»*), ИИ автоматически анализирует контекст, распознает синонимы и без ошибок сопоставляет их со строгими системными BI-полями: `ОЗМ`, `Наименование материала`, `Количество` и `Сумма`. 
*(В случае отсутствия API-ключа, система бесшовно включает No-Code текстовую подстраховку).*

### Б. Динамический Переключатель бизнес-контекста
В левой панели зашит селектор, который заставляет ИИ полностью менять свое аналитическое мышление в зависимости от типа загруженных данных. При нажатии кнопки **«✍️ Сгенерировать ИИ-отчет»**, модель `gemini-3.5-flash` считывает вашу текущую матрицу плотности (как ABC/XYZ, так и RFM по любой выбранной категории) и выдает жесткий профессиональный аудит для генерального директора строго под выбранный процесс:

* **📉 Расход / Потребление ТМЦ цехами**: ИИ трактует группу AZ/сегмент 33 как пики **аварийных, внеплановых ремонтов оборудования** и провала службы ТОиР. Группа CZ/сегмент 11 — ситуативные мелкие заявки цехов «по требованию».
* **📦 Запасы / Складские остатки**: ИИ трактует группу AZ/сегмент 33 как замороженный рабочий капитал, а группу CZ/сегмент 11 — как **мертвый складской хлам и неликвиды**, требующие немедленного списания.
* **📅 Закупки / Бизнес-планы**: ИИ оценивает дисциплину планирования, трактует группу AZ/сегмент 33 как риски срыва крупных инвестпрограмм, а группу CZ/сегмент 11 — как **бюрократический паралич снабжения** мелкими заявками.
* **💰 Продажи / Сбыт (Коммерческий оборот)**: ИИ мгновенно переключается на классический ритейл-анализ. Группа AZ/сегмент 33 — это ваши **товары-локомотивы** (риск упущенной прибыли при дефиците), группа CZ/сегмент 11 — длинный низкомаржинальный хвост ассортимента.
## 🚀 4. Инструкция по эксплуатации (Для Пользователя)

### Шаг 1. Получение бесплатного API ключа ИИ
1. Перейдите по ссылке: `https://google.com`
2. Авторизуйтесь под своей обычной почтой **Google (Gmail)**.
3. В левом верхнем углу нажмите кнопку **`Get API key`** (или `Create API key`).
4. Выберите **`Create API key in new project`**.
5. Скопируйте сгенерированную строку (начинается на `AIzaSy...`).

### Шаг 2. Активация и импорт данных
1. Откройте веб-интерфейс вашего Streamlit-приложения.
2. В левой панели вставьте скопированный ключ в поле **«Введите Gemini API Key:»** и нажмите **`Enter`**.
3. В сайдбаре выберите нужный семантический контекст в списке **«Тип данных (Контекст для AI)»**.
4. Нажмите кнопку **«Browse files»** и загрузите ваш файл Excel или CSV.

### Шаг 3. Гибкий RFM-анализ срезов
1. Перейдите в раздел **«👥 4. RFM-сегментация»**.
2. В верхнем выпадающем списке выберите объект, который хотите категоризировать (например, **«ГОД»** для оценки временных периодов или **«Техническое место»** для аудита узлов оборудования).
3. Настройте глобальные фильтры в сайдбаре (например, выберите конкретный цех). Платформа мгновенно пересчитает гистограмму распределения индивидуально под этот срез.
4. Нажмите кнопку **«👥 Сгенерировать ИИ-отчет по матрице RFM»** — Gemini выдаст детальный текстовый разбор рисков выбранной категории с учетом установленного бизнес-контекста.
## 🛠️ 5. Порядок развертывания и администрирования (Для Разработчика)

Чтобы гарантированно избежать синтаксических сбоев отступов (`IndentationError`) и конфликтов сессионной памяти при обновлении кодов в файле `app.py` на GitHub, строго соблюдайте следующий регламент:

1. **Запись кодов**: Весь рабочий файл `app.py` должен собираться строго на базе словарного роутинга (`router`) и изолированных, функционально закрытых блоков, где Plotly-trace вызовы не разрезаются условиями `if/elif`.
2. **Фиксация коммита**: После внесения изменений нажмите зеленую кнопку **«Commit changes»** в репозитории GitHub.
3. **Мониторинг сборщика**: Откройте боковую консоль управления Streamlit Cloud (черное окно логов справа) и дождитесь системной строки: `Updated app!`.
4. **Глубокий сброс кэша (Hard Reset)**:  
   Если ИИ-модули выдают ошибку кэширования API-эндпоинтов, примените жесткое обнуление сессии:
   * Полностью сотрите API-ключ из поля ввода в сайдбаре приложения (сделайте поле пустым) и нажмите **`Enter`**.
   * Закройте текущую вкладку браузера с дашбордом.
   * В панели управления Streamlit Cloud нажмите чёрную кнопку в правом нижнем углу ➡️ **«Advanced»** ➡️ **«Clear Cache»**, а затем нажмите **«Reboot app»**.
   * Откройте дашборд заново в **новой вкладке в режиме инкогнито** (`Ctrl + Shift + N`), чтобы полностью сбросить внутреннюю память браузера.
